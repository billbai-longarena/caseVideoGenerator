# DECISIONS.md

## Public repository decisions

- The repository is distributed under the MIT License for its own code and documentation.
- The public tree keeps the WL-003 project metadata as the requested demonstration project; rendered media remains local and Git-ignored.
- The WL-003 demonstration media is published as a GitHub Release asset instead of being added to Git history.
- The repository keeps only the 5MB WL-003 preview copy required by the public GitHub Pages player; the high-resolution master remains a Release asset.
- Customer source documents, private brand/client assets, internal operational evidence, credentials, and unrelated generated projects are excluded from both the current tree and rewritten public history.
- Project-local authorized brand assets may be used during private production, but they must not be committed to the public repository.
